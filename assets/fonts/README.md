Font files (`.woff2` / `.ttf`), organized one subfolder per family — e.g. `Quicksand/Quicksand-Regular.ttf`. This is where the theme fonts from the root README's "Theme fonts" section go; `themes/fonts.css` already points here. Folder/file casing has to match exactly (case-sensitive once deployed), so keep it identical to whatever the actual download used. See `assets/README.md` for how to reference a file from here in general.
